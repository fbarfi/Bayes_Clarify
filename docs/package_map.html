How bayes_clarify turns posterior draws into quantities of interest

A fitted model enters through one of three constructors and becomes a Posterior. Four functions turn it into Draws: posterior draws of each quantity, which you summarize, transform, combine and plot.

Architecture

What happens inside one quantity

sim_setx, sim_ame and sim_predictions all run the same five steps, draw by draw. Only the change made in step 1 differs. sim_apply and sim_params skip steps 1 to 3: they work on the parameter draws directly.
